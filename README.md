
# Скрипт для поиска в Википедии с использованием Selenium
## PS04-Selenium

Этот скрипт позволяет искать информацию в Википедии, а также переходить на связанные страницы или использовать другие поисковые системы, такие как Google, Яндекс или Bing. Он использует библиотеку Selenium для автоматизации действий в веб-браузере.

## Зависимости

Для запуска скрипта необходимы следующие компоненты:

1. Python 3.x
2. Библиотека Selenium
3. ChromeDriver (или другой драйвер для браузера)

### Установка зависимостей

1. Установите Python 3.x с официального сайта: https://www.python.org/downloads/
2. Установите Selenium с помощью pip:
    ```bash
    pip install selenium
    ```
3. Установите [ChromeDriver](https://sites.google.com/a/chromium.org/chromedriver/) для работы с Google Chrome. Убедитесь, что версия драйвера соответствует версии вашего браузера Chrome.

## Как использовать

1. Запустите скрипт:
    ```bash
    python script_name.py
    ```
2. Скрипт откроет браузер Google Chrome и перейдет на страницу Википедии.
3. Введите запрос для поиска в Википедии. Скрипт будет искать статьи и отображать результаты.
4. После загрузки страницы статьи, вы сможете выбрать одно из следующих действий:
    - **Листать параграфы**: вывести все параграфы страницы.
    - **Перейти на связанную страницу**: перейти по одной из ссылок на связанную статью.
    - **Создать страницу**: попробовать создать страницу в Википедии (если страница не существует).
    - **Искать в других поисковых системах**: выполнить поиск в Google, Яндексе или Bing.
    - **Выйти**: завершить выполнение скрипта.

## Примечания

- Скрипт использует [ChromeDriver](https://sites.google.com/a/chromium.org/chromedriver/). Если вы хотите использовать другой браузер, скачайте соответствующий драйвер и замените `webdriver.Chrome()` на нужный.
- Убедитесь, что у вас есть активное интернет-соединение для использования поисковых систем.
- Важно, чтобы версия `ChromeDriver` совпадала с версией вашего браузера Chrome.
